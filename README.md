A comprehensive study planning and routine management system for students. Organize your daily schedule, track routines, and generate smart study plans automatically.

## ✨ Features

### 📅 Routine Management
- ✅ Add/Delete daily routines
- ✅ Set start and end times
- ✅ Add location for each activity
- ✅ View routines by day
- ✅ Conflict detection (no overlapping schedules)

### 🧠 Smart Study Plan Generator
- 📚 Auto-generates study sessions based on free time
- ⏰ Customizable session durations (30-180 minutes)
- ☕ Smart break scheduling
- 📊 Study time statistics and efficiency tracking
- 🎯 Subject suggestions for each day

### 👤 User System
- 🔐 Secure login and registration
- 👤 Personalized dashboard
- 💾 Persistent data storage
- 🔒 Password hashing for security

### 🎨 Modern UI
- 🌙 Dark theme design
- 📱 Fully responsive
- 🎯 Interactive and intuitive
- 📊 Visual statistics dashboard
